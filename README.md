# starpick-fulltext-s2
Public-domain book texts (chapter JSON) for 摘星书简 / Starpick Letters, served via jsDelivr.
Texts are in the public domain. Sources: Project Gutenberg e-texts (license header/footer and all references removed, per gutenberg.org/policy/license) and Chinese Wikisource.

## audio/
Original audio close readings produced by 摘星书简 (AI voice), not book texts.
